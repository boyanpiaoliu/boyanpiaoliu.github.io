
# 漂流瓶 App 项目文档

## 一、项目介绍
一款以海洋漂流瓶为主题的陌生人社交 App。

## 二、项目版本
V1.0

## 三、核心功能
1. 手机号注册与登录
2. 扔漂流瓶
3. 随机捡漂流瓶
4. 匿名和公开发布
5. 图片上传
6. 漂流瓶回复
7. 点赞与收藏
8. 关注与好友
9. 私信聊天
10. 热门话题
11. 举报与拉黑
12. 个人中心

## 四、技术规划
- 用户端：Flutter
- 后端：Java Spring Boot
- 管理后台：Vue
- 数据库：MySQL
- 图片存储：云端对象存储

## 五、商业模式
V1.0 免费使用。
后续预留 VIP 会员扩展能力。

## 六、开发目标
先完成 iOS 版本，再支持 Android。
